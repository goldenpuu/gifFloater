# 퇴근 친구

업무 PC 화면 위에 투명 배경의 캐릭터 GIF를 항상 위로 띄워두고, 출근·퇴근 카운트다운과 8가지 상태별 장면을 즐길 수 있는 Python 데스크톱 위젯입니다.

## VS Code에서 실행하기

1. VS Code에서 이 폴더(`gifFloater`)를 엽니다.
2. 필요한 패키지가 없다면 터미널에서 설치합니다:
   ```powershell
   pip install -r python/requirements.txt
   ```
3. 아래 방법 중 하나로 실행합니다:
   - **`F5`** (또는 `Ctrl+F5`): `.vscode/launch.json` 설정으로 실행
   - **`python/gif_floater.py` 열기 → 오른쪽 위 `▶` (Run Python File)** 클릭
   - **터미널 실행**:
     ```powershell
     python python/gif_floater.py
     ```
     (콘솔 창 없이 실행하려면 `pythonw python/gif_floater.py`)

## 주요 기능 및 조작법

- **캐릭터 클릭 / 더블클릭**:
  - **클릭**: `누를 때` 장면과 응원 말풍선(`힘내!`)을 잠깐 보여줍니다.
  - **더블클릭**: 성격에 맞는 점프/흔들기 재롱과 짧은 랜덤 응원 말풍선을 띄웁니다. (말풍선을 클릭하면 바로 닫힙니다.)
- **캐릭터 성격 설정 (5가지)**: 캐릭터마다 **다정함 / 활발함 / 느긋함 / 츤데레 / 성실함** 중 하나를 지정할 수 있습니다. 성격에 따라 좌우 이동 속도와 휴식 시간, 랜덤 응원 주기(9~25분), 응원·상호작용·대화 대사가 달라집니다. (우클릭 → **`[캐릭터] 성격 설정`** 또는 설정 창에서 변경)
- **캐릭터별·캐릭터 간 상호작용 이벤트**:
  - 우클릭 → **`상호작용 하기`** 에서 **쓰담쓰담 / 응원 받기**, **간식 주기**, **하이파이브!**, **콕 찌르기**, **옆 캐릭터와 인사/대화하기**, **모두 함께 합동 응원!**을 실행할 수 있습니다. (트레이 메뉴에서도 캐릭터 간 인사/합동 응원 지원)
  - 여러 캐릭터가 서로 겹치지 않도록 거리를 두고 돌아다니며, 가까이에서 서로 마주 보면 간헐적으로 인사 대화를 주고받습니다.
- **돌아다니기(좌우 이동) & 위치 고정**: 캐릭터가 현재 모니터의 작업 영역 좌우를 주기적으로 돌아다닙니다(멀티 모니터 지원). 우클릭 메뉴의 **`돌아다니기 (좌우 이동)`**, 설정 창 체크박스, 또는 트레이 메뉴 **`모두 돌아다니기 (좌우 이동)`**으로 켜고 끌 수 있으며, **`위치 고정`** 으로 드래그·이동을 잠그거나 **`시계 위로 돌아가기`** 로 작업표시줄 시계 위 기본 위치로 복귀할 수 있습니다.
- **크기 조절**: 캐릭터 위에서 **마우스 휠 스크롤** (또는 `+` / `-` 키, 우클릭 → **`크기`** 프리셋). 말풍선 크기도 캐릭터 크기에 비례해 자동 조절됩니다.
- **GIF 변경**: 우클릭 → **`GIF 파일 직접 선택...`** 또는 **`gifs 폴더에서 선택`** (`gifs/` 폴더에 `.gif`, `.png`, `.webp` 등을 넣으면 자동 표시됩니다)
- **투명도 / 재생 속도 / 좌우 반전**: 우클릭 메뉴에서 설정 (`Space` 키로 일시정지, `F` 키로 좌우 반전)
- **치이카와 캐릭터 프리셋 (6종)**: **치이카와 / 하치와레 / 우사기 / 모몽가 / 세이렌 / 치이카와 & 하치와레** 프리셋이 내장되어 있어 8가지 장면 GIF, 성격, 말풍선 대사를 한 번에 적용하거나 프리셋별로 새 캐릭터를 추가할 수 있습니다. (캐릭터 우클릭 → **`[캐릭터] 캐릭터 프리셋 적용`**, **`프리셋으로 캐릭터 추가 (+)`**, 설정 창 **`프리셋`**, 트레이 메뉴 **`모든 캐릭터에 치이카와 프리셋 배정`**)
- **여러 마리 띄우기**: 우클릭 또는 트레이 아이콘 우클릭 → **`새 캐릭터 추가 (+)`** / **`프리셋으로 캐릭터 추가 (+)`**
- **클릭 통과 모드 (`Ctrl + Alt + L`)** / **빠른 숨기기·보이기 (`Ctrl + Alt + H`)**
- **Windows 시작 시 자동 실행**: 우클릭 또는 트레이 메뉴에서 등록/해제 가능
- **설정 자동 저장**: 캐릭터 위치, 크기, 장면 설정, 근무시간 등이 `python/config_py.json`에 저장됩니다.

## 8가지 장면 및 근무시간 설정

우클릭(또는 트레이 아이콘 우클릭) → **`출근·퇴근 시간 설정...`** 또는 **`[캐릭터] 캐릭터 설정...`** 에서 설정할 수 있습니다.

- **근무 요일 & 시간**: 요일별(월~일) 체크, 출근·퇴근·점심 시간(`0930` 숫자 입력 시 `09:30` 자동 변환) 설정. 쉬는 요일에는 `"쉬는 날"`이 표시됩니다.
- **PC 입력 감지 야근 전환**: 퇴근 시간 이후 PC(키보드/마우스) 활동이 감지되면 **퇴근 5분 경과(`야근 중…`)**, **20분 경과(`집에 가고 싶어…`)** 장면으로 자동 전환되며, 유휴 상태에서는 **`퇴근이다!`** 를 유지합니다.
- **캐릭터별 8가지 장면 설정**: 캐릭터마다 **출근 전 / 출근(2분 전) / 근무 중 / 점심 / 퇴근 / 야근 / 야근 20분 / 누를 때** 장면별 ON/OFF, 이미지(GIF/PNG), 말풍선 문구, `말풍선 보이기` 여부를 개별 지정할 수 있습니다.
- **감자꽃 손글씨 말풍선 (`fonts/hand.ttf`)**: 말풍선은 감자꽃 손글씨 글꼴을 사용하며, 우클릭 **`남은 시간 표시`** 에서 `분으로 (125분 전)` / `시간·분으로 (2시간 5분 전)` / 숨기기를 고를 수 있습니다.
- **캐릭터별 독립 랜덤 응원**: 여러 캐릭터가 있을 때 각 캐릭터가 자신의 성격별 랜덤 주기로 독립 응원 말풍선과 미니 액션을 보여줍니다.
- **미리보기 & 파티클**: 우클릭/트레이 **`미리보기`** 메뉴로 6가지 장면을 즉시 테스트할 수 있으며, 퇴근 시 파스텔 꽃가루 파티클이 터집니다.
